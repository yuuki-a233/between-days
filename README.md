# 日常之间 · 完整项目

米白与雾蓝、文艺温暖的创作与生活社区。包含当前完成的全部用户交付内容。

## 下载使用

- 体验完整社区：进入「日常之间社区」，双击「启动本地测试.cmd」。需要 Node.js 24.15+，首次启动联网下载依赖。
- 只看页面：进入「日常之间-只读演示」，双击 index.html，无需安装或登录。
- Ubuntu：使用「下载包/between-days-community-ubuntu.tar.gz」，按照社区目录的 deploy/Ubuntu部署说明.md 配置。
- 单独压缩包：均放在「下载包」目录。
